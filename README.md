# RunDeck

A gamified task deck in a cyberpunk terminal style. XP, combos, loot drops, a focus timer and a reward shop, with switchable palettes, typefaces and panel ornaments.

It is a single static `index.html` with no build step. Tasks save to the browser's local storage.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy

Import the repo at vercel.com/new. Framework preset: Other. No build command, output directory `.`.
